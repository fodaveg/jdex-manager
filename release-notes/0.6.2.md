## JDex Manager 0.6.2

The Hebra plugin now has its own icon.

### Hebra
- `hebra.json` carries `iconImage`: a 128 px "JD" monogram (PNG embedded as a data URL, 5592 bytes). Hebra paints it in the plugin's row in Settings and wherever the plugin uses its manifest icon.
- The fallback glyph changes from `folder-tree`, which Hebra does not draw (it showed the dotted "missing icon" marker), to `list`. Hebra versions without `iconImage` support show that glyph.
- The build fails if `assets/hebra-icon.png` breaks Hebra's `iconImage` limits (PNG, square, 32 to 128 px, at most 32 KiB), because Hebra rejects the whole manifest on an invalid one.
- Still requires Hebra plugin API 2.1.

### Obsidian
- No behavior changes. Minimum app version remains 1.7.2.
