## JDex Manager 0.6.6

In Hebra, Move in "Process inbox" now goes through the shared engine, like "Move the open note here" since 0.6.5.

### Hebra
- Moving an inbox note to an ID plans and applies with `planMoveIntoId` and `applyMovePlan`. Its two old paths (one failed when the ID had no folder, the other made it) are now one.
- An ID without a folder gets its folder under its category, named as Create ID names it.
- If the ID's folder already holds a note with that name, the move is refused and the note stays in the inbox.
- A note that was moved or renamed after the inbox listed it is not moved.
- Archive to `.09`, the trash and the rest of the inbox are unchanged. The move stays in the undo journal and the view goes on to the next note as before.
- Still requires Hebra plugin API 2.1.

### Obsidian
- No behavior changes. Minimum app version remains 1.7.2.
