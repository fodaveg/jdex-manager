## JDex Manager 0.6.0

Obsidian plugin and external Hebra plugin, same release.

### Hebra
- Requires Hebra plugin API 2.0. JDex now runs in isolated plugin frames and uses the declarative editor API for clickable ID numbers and completions.
- Dialogs, views and settings create their controls in the document supplied by Hebra. Copy commands use Hebra's clipboard API.
- Editor limitation: Hebra sends the plugin only a slice around the visible text. In a very long fenced code block, a JD number may appear clickable if the opening fence is outside that slice.
- Hebra hosts that still implement plugin API 1.x should keep JDex Manager 0.5.1.

### Obsidian
- No behavior changes. Minimum app version remains 1.7.2.
