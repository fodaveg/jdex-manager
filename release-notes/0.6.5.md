## JDex Manager 0.6.5

In Hebra, "Move the open note here" now goes through the shared engine, the same one the Hebra MCP server uses to file into an ID.

### Hebra
- Moving the open note to an ID plans and applies with `planMoveIntoId` and `applyMovePlan`, over a `LibraryMovePort` adapter on the plugin API. The move stays in the undo journal, says "Movida a …" and rebuilds the index as before.
- An ID without a folder gets its folder under its category, named as Create ID names it. Before, the move was refused.
- If the ID's folder already holds a note with that name, the move is refused and nothing changes.
- Moving a note that is already in that folder says so instead of reporting a move.
- The name is still the note's title: Hebra never dates it.
- Still requires Hebra plugin API 2.1.

### Obsidian
- No behavior changes. Minimum app version remains 1.7.2.
