## JDex Manager 0.6.1

JDex Manager 0.6.0, signed for Hebra. The plugin code is identical to 0.6.0.

### Hebra
- This release carries `hebra.json.minisig`, a minisign signature of `hebra.json`. Recent Hebra versions only install or update an external plugin whose release has that signature, so 0.6.0 and 0.5.1 (published without one, and immutable) cannot be installed from them. Install 0.6.1 instead.
- Still requires Hebra plugin API 2.1.

### Release process
- The release workflow no longer publishes: it builds, attests and verifies the draft, then leaves it. `npm run release:sign-publish -- <tag>` signs `hebra.json` with the author's key, uploads the signature to the draft, publishes it and checks that the immutable release has its seven assets. The private key stays on the maintainer's machine and never reaches GitHub.

### Obsidian
- No behavior changes. Minimum app version remains 1.7.2.
