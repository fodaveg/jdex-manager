## JDex Manager 0.5.0

Obsidian plugin and external Hebra plugin, same release.

### Safety of writes and undo
- Every write of the plugin is recorded in the undo journal, effect by effect, with the device that made it; automatic maintenance never redoes an undo.
- Every undo step compares the live state first and changes nothing if the note or file was edited since.
- Undoing a move accepts a file whose creation time changed if its size matches.
- New "Discard last JDex journal entry" command, so an entry that cannot be undone no longer hides earlier ones.
- Journals are merged by identity when `data.json` changes outside the plugin (for example via Sync); journals from 0.3.x/0.4.x are migrated in place.
- Frontmatter corrections write line by line (comments and `jd: 21.20` survive) and journal only the frontmatter block.
- Retire and Normalize check that each frontmatter key was really written.
- Header lists are wrapped only if the body is still the one you previewed.
- Daily audit and health reports edited by hand are kept.
- Category and area numbers are revalidated at confirm time in both hosts.

### Index and lifecycle
- Views follow the index; unloading the plugin stops pending writes and closes its dialogs.
- The index is kept when the JDex folder is renamed or lies outside the system root.
- A repeated number is never merged; ambiguous actions on it are refused.
- A renamed parent is treated as a rename, not as an ID move.
- Automatic maintenance no longer loses or repeats notices; refused fixes warn once.
- A setting changed while `data.json` is being written is no longer reverted.

### Hebra
- Create IDs, areas and categories in prefixed systems (`D01`), with validated system ids.
- Commands on the active note: send to inbox, archive, copy ID / JD path, search category, retire (with confirmation).
- Inbox: preview each note, trash only after confirmation, optionally create a missing folder.
- Rename in pairs works both ways and is tied to the completed rename; a folder rename or move that would renumber an ID or change its category is applied only after you confirm the warning.
- ⌘/Ctrl-click on an ID number opens its note (Alt: the folder); plain clicks no longer hijack editing.
- Rewrites are split into batches of 200 notes, and the undo journal is trimmed to stay within the settings Hebra syncs.
- A partial rewrite caused by an unsaved journal no longer promises undo; notes held back after an undo count as skipped.
- "Go to ID" picker usable from the keyboard with valid ARIA; the repair view shows each fix's effect.
- Built-in templates, missing settings and accessible labels fixed; a new category is checked against its own area's system only.
- Hebra's echo of our own settings saves is ignored.

### Obsidian
- Keyboard-reachable ID panel with live validation and folder suggestions.
- Reading-view numbers answer the middle button and Enter.
- Create ID refuses a missing JDex folder like the other creators; a note of an existing area or category folder is no longer refused.
- A declined folder-settings update is not asked again per descendant.
- Pickers keep your choice even though the modal closes first.
- Deleting a note that an undo trashes leaves header lists to the undo.
- Persistent device identity before Obsidian 1.8.7.

### Interface language
- The Obsidian interface, notices and engine messages are in English and Spanish and follow Obsidian's language.

### Debug log
- Optional debug log note (`Registro de depuración JDex`) in Obsidian and Hebra, off by default; stack locations with spaces in paths are sanitised.

### Under the hood: CI, release provenance, dependencies
- The release workflow builds, hashes and attests the six assets before publishing, verifies the draft against the build, and requires immutable releases.
- Actions are pinned by commit SHA with Dependabot updates; CI is honest about the Hebra bundle and coverage; the gate checks Obsidian API `@since` against `minAppVersion`.
- A script generates a QA vault for manual testing.

### Known limits / needs testing on a real host
- Hebra cannot undo very large rewrites: the journal is trimmed so the synced block stays under 240 KiB.
- In Hebra, a folder rename that would renumber an ID is applied after you confirm the warning; it is not blocked.
- Changing Obsidian's language requires reloading the plugin.
- Hebra must know the `debugLog` settings field when its submodule is bumped.
- The required Hebra plugin API version is unchanged (`^1.2.0`).
- Most of this was verified with test doubles; please try it on a real Obsidian vault and a real Hebra library.
